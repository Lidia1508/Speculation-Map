# Speculation Map

This repository is intended to give a territorial description and/or time evolution of some variables that may affect the housing crisis and the relationship between those, which are: rent price, amount of touristic rentals, amount of buildings available and amount of empty buildings. 

## Getting started 

1. Setup the environment from [environment.yml](environment.yml).
2. Run any of the notebooks in [code/](code/) to obtain the information, maps or plots you desire.

### Notebooks

| Notebook                                                                   | Topic                                                         |
| -------------------------------------------------------------------------- | ------------------------------------------------------------- |
| [`BuildingsAvailable.ipynb`](code/BuildingsAvailable.ipynb)                | Evolution over time of the buildings available in Catalunya by municipalities.                                   |
| [`EmptyBuildings.ipynb`](code/EmptyBuildings.ipynb)            | Empty buildings in 2025 in Catalunya by municipalities|
| [`TouristicRentals.ipynb`](code/TouristicRentals.ipynb)        | Touristic rentals in 2025 Catalunya by municipalitites and comarques.                     |
| [`RentPrice.ipynb`](code/RentPrice.ipynb)                   |Rent price (evolution over time and 2025) and rented houses in 2025 in Catalunya by municipalities and comarques.|
| [`comparativeMultiplot.ipynb`](code/comparativeMultiplot.ipynb)       |Comparison of the different variables related to housing analysed in the other notebooks.|

### Repository

| Folder | Contents |
|---|---|
| `code/` | Course notebooks (committed without outputs: run them yourself) |
| `Data/` | Datasets used by the notebooks, with sources and licences in [`Data/README.md`](Data/README.md) |
